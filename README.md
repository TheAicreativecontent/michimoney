# MichiMoney 🐱💰

**ES** · App kawaii de finanzas personales. Reparte tus ingresos en 3 cuentas (gastos fijos, gastos variables y ahorro) y cuida tu michimoney: el ahorro es tu sueldo de verdad.

**EN** · Kawaii personal finance app. Split your income into 3 pots (fixed costs, variable spending and savings) and take care of your michimoney: savings are your real salary.

## ✨ Privacidad / Privacy

- **ES** · Tus datos viven **solo en tu dispositivo** (localStorage del navegador). No hay servidor, ni cuentas, ni rastreo, ni anuncios. La copia de seguridad (en Ajustes) genera un archivo JSON que tú decides dónde guardar, y puedes restaurarla en cualquier dispositivo.
- **EN** · Your data lives **only on your device** (browser localStorage). No server, no accounts, no tracking, no ads. The backup (in Settings) creates a JSON file you keep wherever you want, and you can restore it on any device.

## 🚀 Usar la app / Use the app

Abre la web y añádela a tu pantalla de inicio (es una PWA instalable). Idiomas: español e inglés, con detección automática.

Open the site and add it to your home screen (installable PWA). Languages: Spanish and English, auto-detected.

## 🛠️ Stack

Un solo archivo React ([MichiFinanzas.jsx](MichiFinanzas.jsx)) compilado a un `index.html` autocontenido con `python build.py`. React 18 + Babel por CDN, CSS propio, gráficas SVG a medida. Sin frameworks, sin build tools, sin dependencias de npm.

One React file compiled into a self-contained `index.html`. No frameworks, no build tools, no npm.
